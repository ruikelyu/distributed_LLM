# 中国制造业各行业典型企业集团规模及行业份额参数调研

**文件：`china_manufacturing_representative_group_parameters.md`**  
**调研日期：2026-08-10**

## 1. 摘要

本报告为中国制造业 AI 算力在**单厂独立部署、集团内部共享部署、全行业联合共享部署**三个尺度上的容量—成本比较构造行业级参数。覆盖 GB/T 4754—2017 制造业 C13—C43 共31个大类。

报告不试图建立真实的“集团—子公司—工厂”所有权数据库，而是为每个行业构造一个**等效典型企业集团**：

- `F_group`：典型集团在中国境内拥有或运营的主要制造工厂、生产基地或综合制造园区数量；
- `s_group`：该典型集团代表的行业活动份额；
- `M_group = 1 / s_group_base`：把一个典型集团的模型结果放大到全行业的等效集团放大系数。

数据质量差异很大。汽车、钢铁、造纸、水泥、家具、部分橡胶制品和废电拆解可以得到较明确的行业集中度；汽车、造纸、粮油、啤酒等还能找到较明确的集团生产基地数量，因此参数可信度较高。相反，木材加工、印刷、文体用品、金属制品、通用设备、其他制造业和修理业产品异质性高，缺少统一的行业集中度和集团基地统计，只能采用行业企业数量、细分市场集中度和上市公司基地布局进行代理。

**重要限制：** 本报告中的 `s_group` 和 `F_group` 是用于情景建模的“代表性中间值”，不是对任何具体真实集团的预测或事实映射。尤其是证据等级 C/D 的行业，Low/Base/High 应被视为敏感性区间。

## 2. 参数定义与估计方法

### 2.1 `s_group`

定义：

```text
s_group = 典型集团占本行业经济或实物活动的份额
```

份额指标优先顺序为：

1. 实物产量或销量；
2. 生产能力；
3. 主营业务收入或行业营业收入；
4. 其他可合理代表行业活动的指标。

如果公开资料只给出行业前 `N` 家企业集中度 `CR_N`，本报告优先使用：

```text
s_group,base = CR_N / N
```

该处理得到的是“前N家平均集团”的等效份额，避免把行业第一名直接当作典型集团。若头部份额高度偏斜，则结合第二至第五名份额或更广义行业口径进行调整。

### 2.2 `F_group`

定义：

```text
F_group = 典型行业龙头集团在中国境内运营的主要制造工厂/生产基地数量
```

计数原则：

- 同一综合园区内多条生产线一般计作1个基地；
- 销售公司、研发中心、办公室、仓库、门店不计；
- 不同城市或相对独立生产设施分别计；
- 海外基地不进入主参数；
- 原料矿山、发电厂只有属于行业核心制造过程时才计入，并须说明；
- 对披露“生产基地”而不披露所有单体工厂的集团，按基地计数，避免重复。

当缺少完整名录时，采用“集团产量÷典型单厂产量”“年报主要基地数”“行业案例类比”等间接方法，并明确标记。

### 2.3 `M_group`

```text
M_group = 1 / s_group_base
```

它是**等效放大系数**，允许为非整数。例如 `s_group_base=0.04` 时，`M_group=25` 表示一个典型集团结果乘25可代表该行业的等效活动总量，绝不表示行业真实存在25个完全相同集团。

### 2.4 AI需求份额假设

基准：

```text
s_group_AI = s_group_base
```

即典型集团的AI服务需求份额与其行业活动份额成比例。该假设对生产、质量、设备、供应链等与制造活动量大致同尺度的AI工作负荷较适用；对办公Copilot、研发AI、自动驾驶仿真、半导体设计等知识密集型任务可能偏差较大。

龙头集团往往数字化程度更高，因此可另设：

```text
s_group_AI / s_group_activity = 1.0–1.5
```

作为可选敏感性，但**不并入本报告基准值**。

### 2.5 证据等级

- **A**：官方/行业协会直接集中度或份额 + 较明确集团基地证据；
- **B**：份额较可靠，基地数来自企业披露/有限样本或反之；
- **C**：份额或基地数至少一项明显依赖间接推算；
- **D**：两项主要依赖跨细分类比或研究者情景。

## 4. 分行业证据说明

### C13 农副食品加工业

1. **份额指标**：优先使用行业营业收入/实物加工量。2021年广义农副食品加工业CR10仅11.63%，说明二位数行业大类非常分散；2024年食用油CR10达73.4%，说明细分市场可以高度集中。
2. **`s_group_base`**：采用广义行业CR10/10≈1.16%，取0.012；没有把金龙鱼的食用油份额直接当成C13典型份额。
3. **工厂证据**：金龙鱼2024年披露全国81个已投产生产基地，是多基地粮油集团的明确上沿锚点。
4. **`F_group_base`**：考虑其他粮油、饲料、肉类加工龙头基地数差异，基准取40，区间15–80。
5. **不确定性**：C13涵盖粮油、饲料、屠宰、水产、果蔬加工，产业组织差异极大。
6. 来源：[农副食品CR10](https://x.qianzhan.com/xcharts/detail/4934ae461c1dcf65.html)；[食用油集中度](https://www.chinabaogao.com/jingzheng/202506/755435.html)；[金龙鱼基地](https://roadshow.cnstock.com/fbh/jly2024)。

### C14 食品制造业

1. **份额指标**：营业收入优于实物量，因为乳制品、调味品、烘焙、糖果、方便食品无法统一成物理单位。
2. **集中度**：公开资料多聚焦子行业，缺少C14统一CR_N，因此基准0.025为代理值。
3. **工厂证据**：伊利2024年报披露全球81个生产基地，但乳业属于基地数较多的高集中子行业，不能直接代表整个C14。
4. **`F_group_base`**：取20，Low/High=8/50。
5. **不确定性**：份额是C级证据，应优先寻找中国食品工业协会百强收入与行业收入的同口径数据。
6. 来源：[伊利2024年报](https://vip.stock.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=11071730)。

### C15 酒、饮料和精制茶制造业

1. **份额指标**：酒类优先销量/产能，软饮料可用销量/收入。
2. **份额**：啤酒和白酒的头部集中度明显高于茶饮料等，因此广义行业典型集团设4.5%。
3. **工厂证据**：华润啤酒截至2024年6月底在中国内地24个省区市运营62间啤酒厂，产能约1940万千升。
4. **`F_group_base`**：基准35，比华润62厂低，以反映白酒等生产基地更少的典型集团。
5. **不确定性**：若单独研究啤酒，F_group和s_group都应提高；若研究精制茶则应降低。
6. 来源：[华润啤酒](https://www.snowbeer.com.cn/companyProfiles/index.html)；[新华社](https://www.news.cn/food/20240819/ad0409b223fb4b7f882ee01ff9aa1c2d/c.html)。

### C16 烟草制品业

1. **特殊制度**：全国由中国烟草体系垄断经营，因此把“中国烟草总公司份额=100%”代入本研究会失去“典型集团”意义。
2. **建模单元**：建议把省级中烟工业公司视作典型生产集团。
3. **`s_group_base`**：按约十余至二十个主要工业主体的数量级设5.5%；不是市场竞争份额。
4. **`F_group_base`**：典型省级中烟通常运营数个主要卷烟厂，设5，区间3–9。
5. **不确定性**：这是制度性情景参数，M_group不能解释成独立企业数量。
6. 来源：[国家烟草专卖局](https://www.tobacco.gov.cn/)。

### C17 纺织业

1. **份额指标**：用纺织业务营业收入。
2. **证据**：2024行业研究明确称中国纺织行业市场集中度较低，百亿元以上纺织业务企业很少但中小企业数量很大。
3. **`s_group_base`**：1.5%，Low/High=0.8%/3%。
4. **`F_group_base`**：参考华孚、新澳、百隆等跨区域布局，取7。
5. **不确定性**：棉纺、毛纺、印染、家纺产业组织不同。
6. 来源：[前瞻产业研究院](https://www.qianzhan.com/analyst/detail/220/240708-0b7f2941.html)。

### C18 纺织服装、服饰业

1. **份额指标**：制造业务收入/订单产能，而不是零售品牌市场份额。
2. **典型结构**：行业大量中小代工厂，少数大型纵向一体化OEM集团集中度较高。
3. **工厂样本**：申洲国际国内主要生产布局包括宁波、安庆、衢州等，海外基地不计入主参数。
4. **参数**：s_group=1.2%，F_group=4，范围2–8。
5. **不确定性**：品牌公司可能自身制造基地很少、依赖供应商，因此不能把品牌销量直接映射成集团工厂数。
6. 来源：[申洲国际2024年报信息](https://finance.sina.com.cn/stock/relnews/hk/2025-04-24/doc-ineuhiqt3405144.shtml)。

### C19 皮革、毛皮、羽毛及其制品和制鞋业

1. **份额指标**：营业收入/鞋履产量。
2. **产业结构**：中国鞋业呈福建、广东、浙江、四川等产业集群分布，供应链中大量中小企业。
3. **参数**：s_group_base=1.5%，F_group_base=6。
4. **不确定性**：鞋、箱包、皮革、羽绒制品差异大，证据等级D。
5. 来源：[中国鞋业产业集群分析](https://www.chinairn.com/hyzx/20240408/1152371.shtml)。

### C20 木材加工和木、竹、藤、棕、草制品业

1. **份额指标**：营业收入。
2. **证据**：2024年上半年木材加工相关企业约1.3万家，行业集中度仍较低。
3. **参数**：s_group_base=0.8%，F_group_base=5。
4. **不确定性**：人造板和木地板头部企业比初级木材加工更集中，统一参数只能作为D级情景。
5. 来源：[木材加工行业概况](https://www.chinairn.com/hyzx/20241012/153856150.shtml)。

### C21 家具制造业

1. **份额指标**：行业营业收入。
2. **集中度**：公开研究给出CR2=5.1%、CR6=10.6%，故CR6/6=1.77%。
3. **`s_group_base`**：取0.018。
4. **`F_group_base`**：顾家、欧派、索菲亚等龙头通常有多个国内制造基地，基准6。
5. **不确定性**：定制家具、软体家具、成品家具差异较大。
6. 来源：[家具集中度](https://finance.sina.com.cn/roll/2024-01-13/doc-inackhse0292073.shtml)；[顾家2024年报摘要](https://m.10jqka.com.cn/sn/20250428/52026199.shtml)。

### C22 造纸和纸制品业

1. **份额指标**：纸及纸板产量。
2. **集中度**：2024 CR3=28.19%、CR5=36.71%、CR10=49.37%。龙头玖龙15.21%、太阳7.67%、山鹰5.31%。

4. **工厂证据**：玖龙官网列出中国10个造纸基地和8个包装基地；本参数只取主要造纸/综合生产基地量级。
5. **`F_group_base`**：10。
6. **证据等级A**。
7. 来源：[造纸集中度](https://www.chinabaogao.com/detail/775446.html)；[玖龙官方基地](https://www.ndpaper.com/sc/business/overview.php)。

### C23 印刷和记录媒介复制业

1. **份额指标**：营业收入。
2. **行业特征**：商业印刷、包装印刷、出版物印刷等区域性强，统一CR_N缺失。
3. **参数**：s_group_base=0.8%，F_group_base=5。
4. **不确定性**：D级情景；下一步应使用中国印刷技术协会百强/包装印刷上市企业数据替换。
5. 来源：[国家统计局](https://www.stats.gov.cn/)。

### C24 文教、工美、体育和娱乐用品制造业

1. **份额指标**：营业收入。
2. **结构**：文具存在得力、晨光等规模集团，但玩具、乐器、工艺美术和体育用品产业组织差异显著。

### C25 石油、煤炭及其他燃料加工业

1. **份额指标**：炼油能力/原油加工量优先。
2. **结构**：中石化、中石油及大型地方炼化占据主要炼油能力，行业明显比普通制造业集中。
3. **`s_group_base`**：取10%，避免直接使用最大央企份额。
4. **`F_group_base`**：按大型集团主要炼厂/炼化一体化基地取15。
5. **不确定性**：C25还包括焦化和煤制燃料，因此炼油代理可能高估全行业集中度。
6. 来源：[中国石油炼油行业分析](https://news.cnpc.com.cn/system/2024/11/21/030148219.shtml)。

### C26 化学原料和化学制品制造业

1. **份额指标**：营业收入/主要化学品产能。

5. **不确定性**：C26是本报告最异质的大类之一。

### C27 医药制造业

### C28 化学纤维制造业

### C29 橡胶和塑料制品业

2. **结构**：结构件、紧固件、工具、金属容器等细分市场大量中小企业。
3. **参数**：s_group_base=1%，F_group_base=6。
4. **证据等级D**：缺少覆盖C33全行业的CR_N。
5. 来源：[国家统计局](https://www.stats.gov.cn/)。

### C34 通用设备制造业

1. **份额指标**：营业收入。
2. **证据**：2024年规上通用设备企业超过3.6万家，说明广义行业非常分散。
3. **参数**：s_group_base=1%，F_group_base=6。
4. **不确定性**：机床、泵阀、压缩机、轴承等细分集中度差异很大。
5. 来源：[企业数量](https://www.chyxx.com/shuju/1207455.html)；[统计局产能利用率](https://www.stats.gov.cn/sj/zxfb/202501/t20250117_1958324.html)。

### C35 专用设备制造业

1. **份额指标**：营业收入。
2. **证据**：2024年规上企业约2.84万家；锂电设备等细分CR10超过50%，但工程机械、半导体设备、农机、矿山设备等差异很大。
3. **参数**：s_group_base=1.2%，F_group_base=6。
4. **不确定性**：高影响研究最好进一步拆工程机械、锂电设备和半导体设备。
5. 来源：[企业数量](https://www.chyxx.com/shuju/1215694.html)；[锂电设备集中度](https://www.chinabaogao.com/detail/788184.html)。

### C36 汽车制造业

1. **份额指标**：汽车销量。
2. **集中度**：中汽协披露2024年前10位企业集团销量2670.4万辆，占总销量84.9%。
3. **`s_group_base`**：严格按CR10/10=8.49%，取0.085。
4. **`F_group_base`**：比亚迪、上汽、吉利、长安、奇瑞等均有多个整车基地；典型集团取9个主要国内整车/综合制造基地。
5. **不确定性**：集团内合资公司和零部件厂不应与整车基地重复计数。
6. **证据等级A**。
7. 来源：[中汽协数据](https://auto.cri.cn/chinanews/20250114/9642f7d2-4de1-2ecd-c6fe-c7ef26f277fe.html)。

### C37 铁路、船舶、航空航天和其他运输设备制造业

1. **份额指标**：完工量/订单或营业收入。
2. **证据**：2023中国船舶制造CR10无论按完工量还是新接订单均超过58%。
3. **`s_group_base`**：C37还包括铁路、航空航天和其他运输设备，因此对全行业下调至5%。
4. **`F_group_base`**：中国船舶、中车、航空工业均呈多基地结构，典型取8。
5. **不确定性**：如果只研究船舶或轨道交通，份额应提高。
6. 来源：[船舶行业CR10](https://www.qianzhan.com/analyst/detail/220/240417-5d8751a9.html)。

### C38 电气机械和器材制造业

1. **份额指标**：销量、产能或营业收入。
2. **结构**：家电、电池、光伏、电机、电缆等子行业均有大型集团，但整个C38并不由同一批企业主导。
3. **参数**：s_group_base=3.5%，F_group_base=15。
4. **不确定性**：用单一宁德时代、美的或海尔份额代表C38会明显高估，因此本报告采用较保守的广义份额。
5. 来源：[国家统计局](https://www.stats.gov.cn/sj/zxfb/202501/t20250117_1958324.html)。

### C39 计算机、通信和其他电子设备制造业

1. **份额指标**：营业收入。
2. **证据**：工信部披露2024年规上电子信息制造业营业收入约16.2万亿元，长三角占28.1%。
3. **结构**：行业存在大型EMS、终端、通信设备、面板集团，也有大量元器件企业。
4. **参数**：s_group_base=3%，F_group_base=20。
5. **不确定性**：半导体、手机、服务器、面板、电子元件高度异质；未来最好使用电子信息百强企业收入与行业总收入直接计算。
6. 来源：[工信部2024电子信息制造业运行情况](https://www.miit.gov.cn/jgsj/yxj/xxfb/art/2025/art_805e7edc1e5444e9b2008354600487aa.html)。

### C40 仪器仪表制造业

1. **份额指标**：营业收入。
2. **代理集中度**：精密仪器2023 CR3接近5%、CR5=5.2%、CR10=5.6%，高度分散。
3. **`s_group_base`**：CR10/10≈0.56%，取0.006。
4. **`F_group_base`**：典型仪器集团主要生产基地数量较少，取4。
5. **不确定性**：精密仪器并非C40全部，但能较好反映分散度。

### C41 其他制造业

1. **份额指标**：营业收入。
2. **问题**：这是统计上的剩余制造类别，缺少稳定统一代表产品。
3. **参数**：s_group_base=0.5%，F_group_base=4。
4. **证据等级D**：两项均为情景值。

### C42 废弃资源综合利用业

1. **份额指标**：处理量/营业收入。
2. **证据**：废电拆解市场中，中再环资、北京新易和格林美约占18%、11%、7%，2024 CR5约46%；但废钢、废纸、废塑料等更分散。
3. **`s_group_base`**：若直接CR5/5为9.2%，对整个C42过高，因此下调至2.5%。
4. **`F_group_base`**：全国性回收处理集团具有多区域处理基地，取8。

3. **参数**：s_group_base=0.5%，F_group_base=6个主要修理/再制造基地。
4. **证据等级D**：缺少统一行业集中度。
5. 来源：[国家统计局](https://www.stats.gov.cn/)。

## 5. 跨行业比较

### 5.1 集中度高、集团份额大的行业

最明显的包括：

- **C36 汽车**：2024 CR10=84.9%，典型集团份额约8.5%；
- **C30 水泥代理的非金属矿物制品**：熟料CR10=60.4%；
- **C22 造纸**：CR10=49.37%；
- **C31 钢铁**：2024 CR10约42%；
- **C25 炼油代理的燃料加工业**：央企与大型炼化集团主导；
- **C15 酒饮料**中的啤酒细分。

这些行业的 `M_group` 较小，集团共享部署已经能获得相当一部分行业级规模经济。

### 5.2 高度分散行业

典型包括：

- C20 木材加工；
- C21 家具；
- C23 印刷；
- C33 金属制品；
- C34 通用设备；
- C40 仪器仪表；
- C41 其他制造；
- C43 修理业。

这些行业典型集团份额通常仅0.5%–2%，`M_group`很高。全行业共享的理论池化收益最大，但现实中跨企业数据治理、商业竞争和网络延迟也是最强约束。

### 5.3 多工厂型集团

大型集团往往拥有较多工厂的行业包括：

- 粮油/农副食品；
- 啤酒/饮料；
- 水泥；
- 汽车；
- 电子制造；
- 电气机械；
- 造纸；
- 综合化工。

直接案例包括：金龙鱼2024年全国81个已投产生产基地、华润啤酒中国内地62间啤酒厂、玖龙纸业中国10个造纸基地。

### 5.4 大型单厂权重更高的行业

钢铁、石化、化纤、电解铝、水泥熟料等单个生产基地本身规模大。这类行业即使 `F_group` 不特别高，单厂AI需求也可能足以提高本地算力利用率，因此集团共享的增量价值更多来自：

- 跨厂负荷互补；
- 模型统一运维；
- 灾备；
- 跨厂知识库；
- 集团级采购议价。

### 5.5 对部署尺度比较最敏感的参数

- `F_group` 决定集团内部可池化的工厂数量；
- `s_group` 决定典型集团占行业活动的比例；
- 对于高 `F_group`、高 `s_group` 的行业，集团共享最有可能逼近行业共享的成本效率；
- 对于低 `s_group` 的高度分散行业，只有跨企业行业平台才能形成真正大规模资源池。

## 6. 参数使用建议

### 6.1 基准模型

如果已有典型单厂AI需求：

```text
Demand_group_i = F_group_base_i × Demand_typical_factory_i
```

如果已有全国行业AI需求：

```text
Demand_group_i = s_group_base_i × Demand_industry_i
```

行业放大：

```text
Industry_cost_i ≈ M_group_base_i × Cost_typical_group_i
```

其中：

```text
M_group_base_i = 1 / s_group_base_i
```

### 6.2 Low/Base/High

Low/High不是统计置信区间，而是产业组织情景：

- `s_group_low`：行业更分散；
- `s_group_high`：行业进一步整合或选取更大龙头；
- `F_group_low`：集团地域集中；
- `F_group_high`：跨省多基地布局明显。

### 6.3 龙头AI采用更快的敏感性

可额外定义：

```text
k_AI_group = 1.0 / 1.2 / 1.5
s_group_AI = min(1, k_AI_group × s_group_activity)
```

Base仍建议1.0。只有获得行业龙头数字化投资、模型调用量或GPU部署的直接证据后，才应把大于1的修正纳入基准。

### 6.4 不应如何解释

- `M_group=25` **不代表行业真实有25个集团**；
- `F_group=10` **不代表所有头部集团恰好有10家工厂**；
- `s_group=0.04` **不代表任何具体企业份额恰好为4%**。

这些是用于容量优化的等效产业结构参数。

## 7. 数据缺口与后续优先级

### 7.1 最弱行业

优先补充：

1. C20 木材加工；
2. C23 印刷；
3. C24 文教工美体育娱乐用品；
4. C33 金属制品；
5. C34 通用设备；
6. C41 其他制造；
7. C43 修理业。

这些行业缺少覆盖整个二位数大类的公开CR_N。

### 7.2 高影响集中度数据缺口

建议优先进一步计算：

1. **C25**：按集团汇总全国炼油能力；
2. **C26**：使用化工百强主营收入与行业收入；
3. **C28**：从中国化纤协会企业产量排名逐家计算CR10；
4. **C32**：分别计算铝、铜集团份额；
5. **C38**：拆分家电、电池、光伏、电机、电缆；
6. **C39**：用电子信息百强收入/工信部行业总收入计算集团份额。

### 7.3 最值得补F_group的行业

对集团共享容量最敏感：

- C13 农副食品；
- C15 酒饮料；
- C25 炼油；
- C26 化工；
- C30 水泥/建材；
- C31 钢铁；
- C36 汽车；
- C38 电气机械；
- C39 电子制造；
- C42 再生资源。

### 7.4 使用收入份额代替实物份额的行业

主要包括C17、C18、C21、C23、C24、C27、C33—C35、C38—C41和C43。这些行业产品异质，实物单位不可加总，因此收入份额通常比“吨数/件数”更适合作为统一经济活动指标。

## 质量控制

1. 31个制造业大类全部覆盖：**是**。
2. 每个行业都有`s_group_low/base/high`：**是**。
3. 每个行业都有`F_group_low/base/high`：**是**。
4. `M_group_base`均按`1/s_group_base`计算：**是**。
5. 已区分直接观测、CR_N计算和研究者情景：**是**。
6. 未把行业第一名直接作为典型集团基准：**是**。
7. 工厂口径排除办公室、仓库、研发中心与同园区重复产线：**是**。
8. 未把等效集团数解释成真实集团数量：**是**。
9. 所有A/B级关键参数均提供可点击来源；C/D级明确标记代理或情景：**是**。
10. 对缺乏公开证据的行业采用圆整情景值而非虚假精确数字：**是**。
